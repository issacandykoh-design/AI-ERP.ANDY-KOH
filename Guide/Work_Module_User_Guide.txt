- Multi-select capability for client-specific filtering

Project Category Filter:
- Categorization based on project types
- Custom categories defined in project settings

Project Member Filter:
- Filter by assigned team members
- Shows projects where specific users are involved

Department Filter:
- Filter projects by department assignment
- Organizational structure-based filtering

Pinned Status Filter:
- All Projects
- Pinned Projects Only
- Non-Pinned Projects

Public Status Filter:
- All Projects
- Public Projects
- Private Projects

Search Functionality:

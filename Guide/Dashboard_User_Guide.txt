1. DASHBOARD OVERVIEW
=====================

The Dashboard is the central hub of the Craveva ERP system, providing users with real-time insights, quick access to key metrics, and personalized widgets based on their roles and permissions.

Main Dashboard Types:
- Admin Dashboard: Comprehensive overview for administrators
- Employee Dashboard: Personalized view for employees
- Client Dashboard: Client-specific information and metrics
- Project Dashboard: Project-focused analytics and data
- HR Dashboard: Human resources metrics and employee data
- Finance Dashboard: Financial analytics and reporting
- Ticket Dashboard: Support ticket management and metrics

Base URL: /dashboard
Advanced Dashboard URL: /dashboard/advanced

2. ADMIN DASHBOARD FEATURES
===========================

2.1 OVERVIEW TAB
----------------
URL: /dashboard/advanced?tab=overview
Route: dashboard.advanced with tab parameter

Key Features:
- Total Clients Widget
  * Displays total number of clients in the system
  * Links to: /clients (clients.index route)
  * Permission required: view_overview_dashboard

- Total Employees Widget
  * Shows total employee count
  * Links to: /employees (employees.index route)
  * Permission required: view_overview_dashboard

- Total Projects Widget
  * Displays total project count
  * Links to: /projects?projects=all (projects.index route)
  * Permission required: view_overview_dashboard

- Total Unpaid Invoices Widget
  * Shows count of pending invoices
  * Links to: /invoices?status=pending (invoices.index route)
  * Permission required: view_overview_dashboard

- Total Hours Logged Widget
  * Displays total time logged across all projects
  * Links to: /timelogs (timelogs.index route)
  * Permission required: view_overview_dashboard

- Total Pending Tasks Widget
  * Shows count of pending tasks
  * Links to: /tasks?status=pending_task&type=public (tasks.index route)
  * Permission required: view_overview_dashboard

- Total Today Attendance Widget
  * Displays today's attendance ratio (present/total employees)
  * Links to: /attendances (attendances.index route)
  * Permission required: view_overview_dashboard

- Total Unresolved Tickets Widget
  * Shows count of open tickets
  * Links to: /tickets?status=open (tickets.index route)
  * Permission required: view_overview_dashboard

- Recent Earnings Chart
  * Bar chart showing income over selected date range
  * Interactive chart with date filtering
  * Permission required: payments module access

- Time Logs Chart
  * Line chart displaying time log trends
  * Shows data for selected date range
  * Permission required: timelogs module access

- Pending Leaves Table
  * Lists leaves awaiting approval
  * Includes employee details, leave dates, and leave types
  * Actions: Approve/Reject leaves directly from dashboard
  * Links to: /leaves/{id} (leaves.show route)
  * Permission required: leaves module access

- Open Tickets Table
  * Displays recent open tickets
  * Shows requester, subject, date, and priority
  * Links to: /tickets/{ticket_number} (tickets.show route)
  * Permission required: tickets module access

2.2 PROJECT TAB
---------------
URL: /dashboard/advanced?tab=project
Route: dashboard.advanced with tab parameter

Key Features:
- Total Projects Widget
  * Shows total project count with date filtering
  * Clickable to filter projects by date range
  * Permission required: view_project_dashboard

- Total Overdue Projects Widget
  * Displays count of overdue projects
  * Links to filtered project list showing overdue projects
  * URL: /projects?status=overdue&deadLineStartDate={start}&deadLineEndDate={end}
  * Permission required: view_project_dashboard

- Total Hours Logged Widget
  * Project-specific time logging metrics
  * Links to: /time-log-report?project=required (time-log-report.index route)
  * Permission required: view_project_dashboard

- Status Wise Project Chart
  * Pie chart showing project distribution by status
  * Interactive chart with full-screen view capability
  * Permission required: view_project_dashboard

- Pending Milestone Table
  * Lists milestones awaiting completion
  * Shows milestone title, cost, and associated project
  * Links to: /projects/{id} (projects.show route)
  * Milestone details modal: /milestones/{id} (milestones.show route)
  * Permission required: view_project_dashboard

6. URL ROUTES AND LINKS
=======================

6.1 MAIN DASHBOARD ROUTES
--------------------------
- GET /dashboard - Main dashboard (redirects based on user role)
- GET /dashboard/advanced - Advanced admin dashboard with tabs
- GET /dashboard/employee - Employee dashboard
- GET /dashboard/client - Client dashboard
- GET /dashboard/checklist - Dashboard checklist view
- GET /dashboard/member/{userId} - Member-specific dashboard
- GET /dashboard/unverified - Unverified account dashboard

6.2 DASHBOARD API ROUTES
-------------------------
- POST /dashboard/widget/{dashboardType} - Update widget settings
- GET /dashboard/week-timelog - Weekly timelog data
- GET /dashboard/private-calendar - Private calendar data
- GET /dashboard/lead-stage/{pipelineId} - Lead pipeline data
- POST /dashboard/beam-auth - Pusher Beam authentication
- POST /dashboard/send-push-notifications - Send push notifications

6.3 AJAX ENDPOINTS
-------------------
All dashboard tabs load content via AJAX:
- /dashboard/advanced?tab=overview (overview.blade.php)
- /dashboard/advanced?tab=project (project.blade.php)
- /dashboard/advanced?tab=client (client.blade.php)
- /dashboard/advanced?tab=hr (hr.blade.php)
- /dashboard/advanced?tab=ticket (ticket.blade.php)
- /dashboard/advanced?tab=finance (finance.blade.php)

6.4 WIDGET LINKS AND REDIRECTS
-------------------------------
Each widget links to relevant sections:
- Clients Widget → /clients
- Employees Widget → /employees
- Projects Widget → /projects?projects=all
- Invoices Widget → /invoices?status=pending
- Tasks Widget → /tasks?status=pending_task&type=public
- Attendance Widget → /attendances
- Tickets Widget → /tickets?status=open
- Time Logs Widget → /timelogs
- Leaves Widget → /leaves/{id}
- Milestones Widget → /milestones/{id}

PAYROLL MODULE - COMPREHENSIVE USER GUIDE

==================================================
OVERVIEW
==================================================

The Payroll module is a comprehensive salary management system that handles employee compensation, salary calculations, overtime management, and payroll reporting. This module provides complete payroll processing capabilities including salary slip generation, payment tracking, tax deductions, and detailed reporting features.

==================================================
MAIN PAYROLL MANAGEMENT INTERFACE
==================================================

ACCESSING THE PAYROLL MODULE
- Navigate to the Payroll section from the main menu
- Route: /account/payroll
- Permission Required: view_payroll (all/added/owned/both)

PAYROLL GENERATION INTERFACE

Filter Section:
1. Year Selection Dropdown
   - Purpose: Select the payroll year for processing
   - Options: Current year and 4 previous years
   - Default: Current year

2. Payroll Cycle Selection
   - Purpose: Choose salary cycle type
   - Options: Monthly, Weekly, Semi-monthly, Bi-weekly
   - Route: Uses payroll cycle configuration

3. Month Selection
   - Purpose: Select specific month for payroll processing
   - Dynamic based on selected cycle
   - Admin users can select specific months

4. Search Field
   - Purpose: Search employees by name or employee ID
   - Real-time filtering capability
   - Placeholder: "Start typing..."

5. Clear Filters Button
   - Purpose: Reset all filter selections
   - Icon: times-circle
   - Functionality: Clears all applied filters

Payroll Generation Form:
1. Include Expense Claims Checkbox
   - Purpose: Include approved expense claims in salary calculation
   - Default: Checked
   - Field Name: includeExpenseClaims

2. Add Timelogs Checkbox
   - Purpose: Include project time logs in salary calculation
   - Default: Unchecked
   - Field Name: addTimelogs

3. Use Attendance Checkbox
   - Purpose: Calculate salary based on attendance records
   - Default: Unchecked
   - Field Name: useAttendance
   - Popover: Explains attendance-based calculation

4. Department Selection
   - Purpose: Filter employees by department
   - Options: All available departments
   - Field: employee_department

5. Employee Selection
   - Purpose: Select specific employees for payroll generation
   - Type: Multi-select dropdown
   - Field: employee_id[]
   - Live search enabled

6. Generate Payslip Button
   - Purpose: Process payroll for selected employees
   - Route: POST /account/payroll/generate
   - Icon: paper-plane
   - Permission Required: add_payroll

PAYROLL DATA TABLE

Quick Actions:
1. Change Status Action
   - Purpose: Bulk update payroll status
   - Options: Generated, Review, Locked, Paid
   - Permission Required: edit_payroll

2. Regenerate Payslip Action
   - Purpose: Regenerate salary slips for selected employees
   - Permission Required: add_payroll

Data Table Features:
- Employee information display
- Salary slip status indicators
- Net salary amounts
- Payment dates
- Action buttons for individual records

Individual Record Actions:
1. View Button
   - Purpose: Display detailed salary slip information
   - Route: GET /account/payroll/{id}
   - Opens modal with complete salary breakdown

2. Edit Button
   - Purpose: Modify salary slip details
   - Route: GET /account/payroll/{id}/edit
   - Permission Required: edit_payroll
   - Available only for non-paid status

3. Download PDF Button
   - Purpose: Download salary slip as PDF
   - Route: GET /account/payroll/download/{id}
   - Generates formatted salary slip document

4. Status Update Button
   - Purpose: Change individual payroll status
   - Route: POST /account/payroll/updateStatus
   - Status options: Generated, Review, Locked, Paid

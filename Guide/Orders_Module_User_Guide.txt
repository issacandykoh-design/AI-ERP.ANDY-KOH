1. ORDERS MODULE OVERVIEW
===========================================

The Orders module is a comprehensive order management system that handles the complete order lifecycle from creation to completion. It supports multiple order statuses, payment processing, client management, and integration with invoicing and payment systems.

Key Features:
- Complete order lifecycle management
- Multiple payment gateway integration
- Client and project association
- Product and inventory management
- Tax calculation and discount handling
- PDF generation and downloads
- Status tracking and notifications

Main Access Route: /orders
Controller: OrderController.php
Primary Views: resources/views/orders/

===========================================
2. ORDERS LIST MANAGEMENT
===========================================

2.1 ORDERS INDEX PAGE
Route: /orders (GET)
Method: OrderController@index
View: resources/views/orders/index.blade.php

The Orders index page displays a comprehensive list of all orders with advanced filtering and management capabilities.

2.1.1 FILTER OPTIONS
- Duration Filter: Filter orders by date range (Today, Yesterday, This Week, Last Week, This Month, Last Month, Custom Range)
- Client Filter: Filter orders by specific client
- Project Filter: Filter orders by associated project
- Status Filter: Filter by order status (Pending, On-Hold, Failed, Processing, Completed, Canceled, Refunded)
- Search Field: Search orders by order number, client name, or other criteria

2.1.2 ACTION BUTTONS
- Add Order Button: Create new order (Route: /orders/create)
  - Visibility: Controlled by 'add_order' permission
  - Opens order creation form in right modal

2.1.3 BULK ACTIONS
- Delete Selected: Remove multiple orders simultaneously
- Change Status: Update status for multiple orders
- Quick Actions Dropdown: Access to bulk operations

2.1.4 ORDER LIST DISPLAY
Each order row displays:
- Order Number: Unique identifier
- Client Name: Associated client information
- Project: Linked project (if applicable)
- Order Date: Creation date
- Status: Current order status with color coding
- Total Amount: Order total with currency
- Actions: Individual order operations

===========================================
3. ORDER CREATION
===========================================

3.1 CREATE NEW ORDER
Route: /orders/create (GET)
Method: OrderController@create
View: resources/views/orders/ajax/admin_create.blade.php

3.1.1 ORDER INFORMATION SECTION
- Order Number: Auto-generated unique identifier
- Client Selection: Dropdown with client search functionality
  - Displays billing address automatically
  - Shows shipping address or option to add
- Project Selection: Associated project dropdown (filtered by client)
- Company Address: Select generating company address
- Order Status: Initial status selection (Pending, On-Hold, Failed, Processing, Completed, Canceled)

3.1.2 PRODUCT SELECTION
- Product Category Filter: Filter products by category
- Product Dropdown: Select from available products
- Add New Product: Quick product creation (with permissions)

3.1.3 ORDER ITEMS SECTION
For each item:
- Description: Product/service name
- HSN/SAC Code: Tax classification code (if enabled)
- Quantity: Number of units
- Unit Type: Measurement unit
- SKU: Stock keeping unit
- Unit Price: Price per unit
- Tax: Applicable taxes
- Amount: Calculated total per item

3.1.4 CALCULATIONS SECTION
- Subtotal: Sum of all items
- Discount: Percentage or fixed amount discount
- Tax: Calculated tax amounts
- Total: Final order amount

3.1.5 ADDITIONAL INFORMATION
- Client Note: Internal notes for the order
- Custom Fields: Additional order attributes
- Shipping Address: Delivery address management

3.1.6 ACTION BUTTONS
- Submit: Create the order (Route: /orders - POST)
- Cancel: Return to orders list

5. ORDER EDITING AND UPDATES
===========================================

5.1 EDIT ORDER
Route: /orders/{id}/edit (GET)
Method: OrderController@edit
View: resources/views/orders/ajax/edit.blade.php

5.1.1 EDITABLE FIELDS
- Order Status: Update current status
- Company Address: Change generating address
- Order Items: Modify quantities, prices, descriptions
- Discount: Adjust discount values
- Notes: Update client notes
- Custom Fields: Modify additional attributes

5.1.2 RESTRICTIONS
- Completed, Canceled, and Refunded orders cannot be edited
- Permission-based editing controls
- Item modifications with real-time calculations

5.1.3 UPDATE PROCESS
Route: /orders/{id} (PUT)
Method: OrderController@update
- Validates all item data
- Updates order totals
- Handles invoice generation (if status changed to completed)
- Manages payment creation

===========================================
6. ORDER STATUS MANAGEMENT
===========================================

6.1 AVAILABLE STATUSES
- Pending: Initial order state
- On-Hold: Temporarily suspended
- Failed: Order processing failed
- Processing: Order being fulfilled
- Completed: Order successfully fulfilled
- Canceled: Order canceled
- Refunded: Order refunded

6.2 STATUS CHANGE OPERATIONS
Route: /orders/change-status (POST)
Method: OrderController@changeStatus

6.2.1 STATUS CHANGE EFFECTS
- Completed Status: Automatically creates invoice and payment
- Refunded Status: Creates credit note (if conditions met)
- Bank Account Selection: Required for completed orders

6.2.2 AUTOMATED PROCESSES
- Invoice Generation: Automatic for completed orders
- Payment Record Creation: Links to invoice
- Credit Note Creation: For refunded orders
- Notification Triggers: Status change notifications

13. ROUTE REFERENCE GUIDE
===========================================

13.1 MAIN ROUTES
- GET /orders - Orders list page
- GET /orders/create - Create new order form
- POST /orders - Store new order
- GET /orders/{id} - View order details
- GET /orders/{id}/edit - Edit order form
- PUT /orders/{id} - Update order
- DELETE /orders/{id} - Delete order

13.2 AJAX ROUTES
- GET /orders/add-item - Add product to order
- POST /orders/change-status - Update order status
- GET /orders/{id}/download - Download order PDF
- GET /orders/stripe-modal - Stripe payment form
- GET /orders/offline-payment-modal - Offline payment form

13.3 PAYMENT ROUTES
- POST /orders/payment-failed/{id} - Handle payment failure
- POST /orders/save-stripe-detail - Process Stripe payment
- GET /paypal/{id}?type=order - PayPal payment processing

13.4 UTILITY ROUTES
- GET /orders/clients - Get client data
- POST /orders/make-invoice - Generate invoice from order
- POST /orders/store-quantity - Update item quantities

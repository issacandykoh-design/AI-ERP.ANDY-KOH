QR CODE MODULE - COMPREHENSIVE USER GUIDE
==================================================

OVERVIEW
==================================================

The QR Code module is a comprehensive digital tool management system that enables users to create, customize, manage, and track various types of QR codes for business and personal use. This module supports multiple QR code formats including text, URL, email, WhatsApp, WiFi credentials, payment information, and more, with extensive customization options for branding and design.

Key Features:
- Multi-format QR code generation (13 different types)
- Advanced customization options (colors, size, margins, logos)
- Real-time preview functionality
- Multiple download formats (PNG, SVG, PDF)
- Comprehensive management interface
- Integration with attendance system
- Permission-based access control

==================================================
MAIN NAVIGATION
==================================================

Primary Access Points:

1. QR Code Management Dashboard
   - Route: /account/qrcode
   - Purpose: Main interface for QR code management
   - Access Level: Based on user permissions

2. QR Code Creation Interface
   - Route: /account/qrcode/create
   - Purpose: Create new QR codes with customization options
   - Access Level: Users with 'add_qrcode' permission

3. QR Code Preview System
   - Route: /account/qrcode/preview (AJAX)
   - Purpose: Real-time QR code preview during creation
   - Access Level: Users with 'view_qrcode' permission

4. QR Code Download Service
   - Route: /account/qrcode/download/{id}/{format}
   - Purpose: Download QR codes in various formats
   - Access Level: Users with 'view_qrcode' permission

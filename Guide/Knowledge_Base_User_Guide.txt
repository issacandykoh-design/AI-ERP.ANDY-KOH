KNOWLEDGE BASE MODULE - COMPREHENSIVE USER GUIDE

==================================================
OVERVIEW
==================================================

The Knowledge Base module is a centralized information management system that allows organizations to create, organize, and share knowledge articles with employees and clients. The module provides comprehensive functionality for creating articles with rich content, categorizing information, managing file attachments, and controlling access permissions based on user roles.

==================================================
MAIN NAVIGATION ACCESS
==================================================

The Knowledge Base module is accessible through the main navigation menu:
- Menu Item: "Knowledge Base"
- Route: /knowledgebase
- Icon: Knowledge base icon in the sidebar
- Permission Required: view_knowledgebase
- Visibility: Available to users with appropriate permissions

==================================================
MAIN INTERFACE (INDEX PAGE)
==================================================

URL: /knowledgebase
Route Name: knowledgebase.index
Template: resources/views/knowledge-base/index.blade.php

The main Knowledge Base interface consists of several key components:

1. SIDEBAR NAVIGATION
   - Category Filter Sidebar: Left-side panel displaying all knowledge base categories
   - Search Functionality: Search input field to filter categories
   - "All" Category: Default option to view all articles
   - Dynamic Category Links: Each category links to filtered view (/knowledgebase?id={category_id})

2. HEADER SECTION
   - Page Title: "Knowledge Base" heading
   - Add Knowledge Base Button: Primary action button (requires add_knowledgebase permission)
     * Link: /knowledgebase/create
     * Class: openRightModal
     * Text: "Add Knowledge Base"
     * Icon: Plus icon
   - Add Category Button: Secondary action button
     * ID: addCategory
     * Text: "Add Knowledge Base Category"
     * Icon: Plus icon
     * Action: Opens category management modal

3. SEARCH AND FILTER SECTION
   - Search Input Field:
     * ID: search-text-field
     * Placeholder: "Start typing..."
     * Function: Real-time search through knowledge base articles
   - Clear Filters Button:
     * ID: reset-filters
     * Text: "Clear Filters"
     * Icon: Times circle
     * Visibility: Hidden by default, shown when filters are active

4. DATA TABLE
   The main content area displays a table with the following columns:
   - Serial Number (#): Sequential numbering of articles
   - Knowledge Heading: Article title with clickable link to detail view
   - Knowledge Category: Category name associated with the article
   - To: Target audience (Employee/Client)
   - Action: Edit and delete buttons (permission-based)

   Table Features:
   - Responsive Design: Adapts to different screen sizes
   - Permission-Based Display: Articles shown based on user roles
   - Interactive Links: Article headings link to detail view
   - Action Buttons: Edit and delete options with appropriate permissions

KNOWLEDGE BASE ARTICLE CREATION
==================================================

URL: /knowledgebase/create
Route Name: knowledgebase.create
Template: resources/views/knowledge-base/ajax/create.blade.php

The article creation interface provides comprehensive functionality for creating new knowledge base articles:

1. FORM HEADER
   - Title: "Knowledge Details"
   - Modal-based Interface: Opens in right-side modal

2. RECIPIENT SELECTION
   - Radio Button Options:
     * To Employee: fieldId="toEmployee", fieldValue="employee" (default selected)
     * To Client: fieldId="toClient", fieldValue="client" (conditional visibility)
   - Conditional Display: Client option only shown if clients module is enabled

3. ARTICLE DETAILS SECTION
   - Heading Input Field:
     * Field ID: heading
     * Field Name: heading
     * Required: Yes
     * Placeholder: "Knowledge Heading"
   
   - Category Selection:
     * Field ID: category
     * Type: Dropdown with search functionality
     * Required: Yes
     * Options: Populated from existing categories
     * Add Category Button: Inline button to create new categories

4. CONTENT EDITOR
   - Rich Text Editor:
     * ID: description
     * Type: Quill editor with mention functionality
     * Features: Full formatting options, mentions, rich content support
   - Hidden Textarea: description-text (stores final content)

5. FILE UPLOAD SECTION
   - Dropzone Integration:
     * ID: file-upload-dropzone
     * Multiple File Support: Yes
     * Drag and Drop: Enabled
     * File Type Restrictions: Based on system configuration
     * Max File Size: Configurable
     * Max Files: Configurable

6. ACTION BUTTONS
   - Save Button:
     * ID: save-knowledgebase
     * Text: "Save"
     * Icon: Check mark
     * Function: Submits form and processes file uploads
   - Cancel Button:
     * Link: Returns to knowledge base index
     * Text: "Cancel"

   - Cancel Button: Returns to knowledge base index without saving

   - Function: Returns to default view showing all articles

PERMISSION SYSTEM
==================================================

The Knowledge Base module implements a comprehensive permission system:

1. VIEW PERMISSIONS
   - Permission: view_knowledgebase
   - Function: Controls access to knowledge base module
   - Scope: Required for basic module access

2. ADD PERMISSIONS
   - Permission: add_knowledgebase
   - Function: Controls ability to create new articles
   - UI Impact: Shows/hides "Add Knowledge Base" button

3. EDIT PERMISSIONS
   - Permission: edit_knowledgebase
   - Levels: 'all' (edit any article) or 'added' (edit own articles only)
   - UI Impact: Shows/hides edit buttons and options

4. DELETE PERMISSIONS
   - Permission: delete_knowledgebase
   - Levels: 'all' (delete any article) or 'added' (delete own articles only)
   - UI Impact: Shows/hides delete buttons and options

5. ROLE-BASED VISIBILITY
   - Article Display: Articles shown based on user roles and target audience
   - Admin Access: Administrators can view all articles regardless of target audience
   - User Filtering: Regular users only see articles targeted to their role

==================================================
TROUBLESHOOTING GUIDE
==================================================

Common issues and solutions for the Knowledge Base module:

1. ARTICLE CREATION ISSUES
   - Problem: Cannot create new articles
   - Solution: Verify add_knowledgebase permission is assigned
   - Check: Ensure categories exist before creating articles

2. FILE UPLOAD PROBLEMS
   - Problem: Files not uploading
   - Solution: Check file size limits and allowed file types
   - Verify: Storage permissions and available disk space

3. SEARCH NOT WORKING
   - Problem: Search returns no results
   - Solution: Verify database indexes and search configuration
   - Check: AJAX endpoints are accessible and functional

4. PERMISSION ERRORS
   - Problem: Users cannot access certain features
   - Solution: Review and update user permissions
   - Verify: Role assignments and permission inheritance

5. DISPLAY ISSUES
   - Problem: Articles not displaying correctly
   - Solution: Check responsive design and CSS conflicts
   - Verify: JavaScript functionality and browser compatibility

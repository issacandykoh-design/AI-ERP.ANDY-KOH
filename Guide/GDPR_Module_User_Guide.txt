GDPR MODULE USER GUIDE

OVERVIEW
The GDPR (General Data Protection Regulation) module provides comprehensive data privacy and protection features for managing customer and lead data in compliance with European data protection regulations. This module enables organizations to handle data subject rights, consent management, data portability, and data erasure requests.

MAIN NAVIGATION ACCESS
- Access GDPR settings through the main navigation menu item "GDPR" (visible based on user permissions)
- GDPR settings are also accessible through the settings sidebar menu
- Public GDPR forms are available for leads through dedicated public URLs

GDPR SETTINGS MANAGEMENT

1. MASTER GDPR TOGGLE
Location: GDPR Settings > Main Dashboard
URL: /gdpr-settings
Description: The master toggle enables or disables the entire GDPR functionality system-wide.
Features:
- Toggle switch to enable/disable GDPR compliance features
- Status indicator showing "Enabled" or "Disabled" state
- Automatic page reload after toggle change to show/hide GDPR settings panel
- AJAX-powered real-time updates without full page refresh

2. GENERAL SETTINGS TAB
Location: GDPR Settings > General Tab
URL: /gdpr-settings (default tab)
Description: Configure general GDPR display and navigation settings.
Features:
- Enable GDPR link in main navigation menu
- Enable GDPR link in website footer
- Configure top information block for public pages
- Save button to apply general settings changes
- Real-time form validation and submission

3. RIGHT TO BE INFORMED TAB
Location: GDPR Settings > Right to be Informed Tab
URL: /gdpr-settings?tab=right-to-informed
Description: Manage terms and conditions and privacy policy settings for customers.
Features:
- Enable/disable terms and conditions requirement
- Enable/disable privacy policy requirement
- Upload and manage terms and conditions documents
- Upload and manage privacy policy documents
- Configure display settings for legal documents
- Save button to apply informed consent settings

4. RIGHT TO ACCESS TAB
Location: GDPR Settings > Right to Access Tab
URL: /gdpr-settings?tab=right-to-access
Description: Configure settings for allowing leads to update their data through public forms.
Features:
- Enable/disable public lead data editing capability
- Configure public page consent information block
- Set access permissions for lead data modification
- Save button to apply access rights settings

5. RIGHT TO DATA PORTABILITY TAB
Location: GDPR Settings > Right to Data Portability Tab
URL: /gdpr-settings?tab=right-to-data-portability
Description: Enable and configure customer data export functionality.
Features:
- Enable/disable customer data export feature
- Configure data export format and scope
- Set data portability permissions
- Save button to apply data portability settings

6. RIGHT TO ERASURE TAB
Location: GDPR Settings > Right to Erasure Tab
URL: /gdpr-settings?tab=right-to-erasure
Description: Manage data removal request settings for customers and leads.
Features:
- Enable/disable customer data removal requests
- Enable/disable lead data removal requests
- Configure removal request approval workflow
- Set data retention policies
- Save button to apply erasure settings

7. CONSENT MANAGEMENT TAB
Location: GDPR Settings > Consent Lists Tab
URL: /gdpr-settings?tab=consent-lists
Description: Manage consent purposes and customer consent settings.
Features:
- Enable/disable consent requirement for customers
- Enable/disable consent requirement for leads
- Create new consent purposes with "Add Consent" button
- Edit existing consent purposes with edit buttons
- Delete consent purposes with delete buttons
- Quick actions dropdown for bulk operations
- Apply button for executing bulk actions
- Data table with consent purpose listings

REMOVAL REQUEST MANAGEMENT

8. CUSTOMER REMOVAL REQUESTS
Location: GDPR Settings > Removal Requests Tab
URL: /gdpr-settings?tab=removal-requests
Description: Review and manage customer data removal requests.

- Request details including name, description, status, and submission date
- Quick actions dropdown for bulk operations (approve, reject, delete)
- Status change functionality with dropdown selection
- Apply button for executing bulk actions
- Individual request approval/rejection buttons
- Checkbox selection for bulk operations
- Search and filter capabilities

9. LEAD REMOVAL REQUESTS
Location: GDPR Settings > Lead Removal Requests Tab
URL: /gdpr-settings?tab=lead-removal-requests
Description: Review and manage lead data removal requests.
Features:
- Data table displaying all lead removal requests
- Request details including lead information, description, and status

- Search and filter functionality

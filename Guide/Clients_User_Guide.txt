CLIENTS SECTION - COMPREHENSIVE USER GUIDE

===========================================
OVERVIEW
===========================================

The Clients section provides comprehensive client relationship management functionality within the ERP system. This module enables users to manage client information, contacts, documents, notes, and track various business interactions including projects, invoices, payments, and orders.

===========================================
MAIN CLIENT LISTING PAGE
===========================================

URL: /clients
Route: clients.index
Description: The primary interface for viewing and managing all clients in the system.

FILTERING AND SEARCH CAPABILITIES:

1. Date Range Filter
   - Function: Filter clients by creation date range
   - Implementation: Uses datatableRange component
   - Usage: Select start and end dates to filter client records

2. Client Selection Filter
   - Function: Filter by specific client
   - Field: client dropdown
   - Usage: Select individual client from dropdown list

3. Category Filter
   - Function: Filter clients by category
   - Field: filter_category_id
   - Usage: Select client category to narrow results

4. Sub-Category Filter
   - Function: Filter clients by sub-category
   - Field: filter_sub_category_id
   - Dependency: Dynamically loads based on selected category
   - AJAX Endpoint: get_client_sub_categories

5. Project Filter
   - Function: Filter clients by associated project
   - Field: project_id
   - Usage: Select project to show related clients

6. Contract Type Filter
   - Function: Filter by contract type
   - Field: contract_type_id
   - Usage: Filter clients based on contract arrangements

7. Country Filter
   - Function: Filter clients by country
   - Field: country_id
   - Usage: Select country to show clients from specific location

8. Status Filter
   - Function: Filter by active/inactive status
   - Options: Active, Inactive
   - Usage: Toggle between active and inactive clients

9. Verification Status Filter
   - Function: Filter by client verification status
   - Usage: Show verified or unverified clients

10. Search Functionality
    - Field: search-text-field
    - Function: General text search across client data
    - Implementation: Real-time search with AJAX data loading

ACTION BUTTONS AND CONTROLS:

1. Add New Client Button
   - URL: /clients/create
   - Route: clients.create
   - Function: Navigate to client creation form
   - Permission: add_clients

2. Import Clients Button
   - URL: /clients/import
   - Route: clients.import
   - Function: Bulk import clients from file
   - Permission: add_clients

3. View Toggle Buttons
   - All Clients View: /clients
   - Unverified Clients View: Separate view for pending verification

4. Quick Actions
   - Change Status: Bulk status modification for selected clients
   - Delete: Bulk deletion of selected clients
   - Implementation: Uses SweetAlert for confirmation

5. Individual Row Actions
   - Verify User: Approve client verification (.verify-user)
   - Delete Row: Remove individual client (.delete-table-row)
   - Edit: Modify client information

6. Reset Filters Button
   - Function: Clear all applied filters
   - Visibility: Shows when filters are active

===========================================
CLIENT CREATION
===========================================

URL: /clients/create
Route: clients.create
Description: Comprehensive form for adding new clients to the system.

FORM SECTIONS:

1. Personal Information
   - Salutation: Title selection (Mr., Mrs., Ms., Dr., etc.)
   - Full Name: Client's complete name
   - Email Address: Primary email contact
   - Country: Country selection with flag display
   - Mobile Number: Phone number with country code
   - Gender: Gender selection
   - Language: Preferred language setting
   - Profile Picture: Image upload for client avatar

2. Company Details
   - Company Name: Business name
   - Website: Company website URL
   - Tax Name: Legal business name for tax purposes
   - GST Number: Tax identification number
   - Office Phone: Business phone number
   - City: Business location city
   - State: Business location state/province
   - Postal Code: ZIP/postal code
   - Address: Complete business address
   - Company Logo: Business logo upload

3. Administrative Settings
   - Client Category: Business category classification
   - Sub-Category: Detailed business classification
   - Client Login Permission: Enable/disable client portal access
   - Email Notifications: Configure notification preferences
   - Added By: User who created the client record

4. Additional Information
   - Shipping Address: Delivery address if different from business address
   - Telegram User ID: Integration with Telegram messaging
   - Notes Section: Additional client information
   - Custom Fields: Configurable additional data fields

FORM FUNCTIONALITY:

1. Dynamic Sub-Category Loading
   - AJAX call triggered by category selection
   - Endpoint: Loads relevant sub-categories

2. Country-Based Phone Code
   - Automatic phone code update based on country selection
   - Real-time field updates

3. Save Options
   - Standard Save: Save and return to client list
   - Save and Add More: Save current client and create another

4. Lead Integration
   - Pre-fill functionality when converting from lead
   - leadID parameter support

5. Category Management
   - Add New Category: Modal for creating client categories
   - Add New Sub-Category: Modal for creating sub-categories
   - Permission-based visibility

FORM SUBMISSION:
- Endpoint: /clients (POST)
- Route: clients.store
- Method: AJAX submission with $.easyAjax
- Validation: Server-side and client-side validation

CLIENT DOCUMENTS MANAGEMENT
===========================================

Description: Comprehensive file management system for client-related documents.

DOCUMENT DISPLAY:
- File card interface with thumbnails
- Document type icons for non-image files
- Upload date and file information
- Permission-based action menus

DOCUMENT ACTIONS:

1. View Document
   - Direct file viewing for supported formats
   - New tab opening for document review

2. Download Document
   - URL: /client-docs/{hash}/download
   - Route: client-docs.download
   - Secure file download with hash-based URLs

3. Edit Document
   - Modal-based editing interface
   - File name modification
   - File replacement capability
   - Supported formats: txt, pdf, doc, xls, xlsx, docx, rtf, png, jpg, jpeg, svg

4. Delete Document
   - Confirmation dialog before deletion
   - Permanent file removal

DOCUMENT EDITING FORM:
- File Name: Editable document name
- File Upload: Replace existing file
- Format Validation: Restricted file types
- AJAX submission: /client-docs/{id} (PUT)

PERMISSIONS:
- add_client_document: Upload new documents
- view_client_document: View and download documents
- edit_client_document: Modify document information
- delete_client_document: Remove documents

PERMISSION LEVELS:
- all: Full access to all client documents
- added: Access to documents uploaded by the user
- owned: Access to documents for owned clients
- both: Combined added and owned permissions

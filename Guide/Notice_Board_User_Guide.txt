NOTICE BOARD MODULE - COMPREHENSIVE USER GUIDE

OVERVIEW
The Notice Board module is a centralized communication system that enables administrators and authorized users to create, manage, and distribute notices to employees and clients. This module provides comprehensive functionality for internal communication, announcements, and information sharing within the organization.

MAIN NAVIGATION ACCESS
- Primary Access: Navigate to "Notice Board" from the main navigation menu
- Dashboard Widget: Access recent notices through the employee dashboard widget
- Direct URL: /notices (requires authentication)

MAIN INTERFACE (INDEX PAGE)

Filter Section
The Notice Board index page provides comprehensive filtering options:

Date Range Filter:
- Start Date Field: Select beginning date for notice filtering
- End Date Field: Select ending date for notice filtering  
- Date Range Picker: Interactive calendar widget for easy date selection
- Filter Button: Apply selected date range filters
- Reset Filter Button: Clear all applied filters and return to default view

Search Functionality:
- Search Input Field: Enter keywords to search notice headings and content
- Real-time Search: Automatic filtering as you type
- Search Reset: Clear search terms using the reset filter option

Action Buttons:
- Add Notice Button: Create new notice (visible based on user permissions)
  Route: /notices/create
  Permission: add_notice
- Export Options: Export notice data in various formats (Excel, CSV, PDF)
- Bulk Actions: Perform actions on multiple selected notices

Data Table Display:
The main data table shows notice information with the following columns:
- Checkbox Column: Select individual notices for bulk actions
- Action Column: View, edit, and delete options for each notice
- Heading Column: Notice title/subject
- Created At Column: Notice creation date and time
- To Column: Recipients (employees/clients) information

Individual Notice Actions:
- View Button: Open notice details in modal popup
  Route: /notices/{id}
  JavaScript: $.ajaxModal function
- Edit Button: Modify existing notice (permission-based)
  Route: /notices/{id}/edit
  Permission: edit_notice
- Delete Button: Remove notice with confirmation dialog
  Route: DELETE /notices/{id}
  Permission: delete_notice

Bulk Actions:
- Select All Checkbox: Choose all visible notices
- Delete Selected: Remove multiple notices simultaneously
- Confirmation Dialog: SweetAlert confirmation before bulk deletion

NOTICE CREATION INTERFACE

Access Methods:
- Click "Add Notice" button from main interface
- Direct route: /notices/create
- Modal popup: AJAX-loaded form

Form Fields and Components:

Recipient Selection:
- Radio Button Options:
  * Employee: Send notice to internal staff members
  * Client: Send notice to external clients
- Dynamic Field Display: Form fields change based on selection

Employee Selection (when Employee is selected):
- Department Dropdown: Filter employees by department
  Route: GET /employees-by-department
  JavaScript: Dynamic loading via $.easyAjax
- Employee Multi-select: Choose specific employees
  Component: Bootstrap Select Picker
  Feature: Search and multiple selection capability

Client Selection (when Client is selected):
- Client Multi-select: Choose specific clients
  Component: Bootstrap Select Picker
  Feature: Search and multiple selection capability

Notice Content Fields:
- Heading Input: Notice title/subject (required field)
- Department Dropdown: Categorize notice by department
- Notice Details: Rich text editor for notice content
  Component: Quill Editor
  Features: Text formatting, lists, links, styling options

File Attachment System:
- Dropzone Component: Drag-and-drop file upload interface
- File Upload Features:
  * Multiple file selection
  * Drag-and-drop functionality
  * File size validation (configurable limit)
  * File type restrictions
  * Upload progress indication
  * Error handling and validation messages
- CSRF Protection: Automatic token inclusion for security

Form Submission:
- Save Button: Submit notice for creation
  Route: POST /notices
  Method: AJAX submission via $.easyAjax
- Cancel Button: Close form without saving
- Validation: Client-side and server-side validation
- Success Handling: Automatic redirection or modal closure

NOTICE EDITING INTERFACE

Access Methods:
- Click "Edit" button from notice list or detail view
- Direct route: /notices/{id}/edit
- Permission required: edit_notice

Pre-filled Form Fields:
All form fields are populated with existing notice data:
- Recipient type (Employee/Client) pre-selected
- Selected employees/clients displayed
- Notice heading filled
- Department selected
- Notice content loaded in Quill editor
- Existing attachments displayed

Edit-Specific Features:
- Existing File Management: View and delete current attachments
- Content Preservation: Maintain formatting in rich text editor
- Selective Updates: Modify only necessary fields
- Version Control: Track changes and modifications

Form Submission:
- Update Button: Save changes to existing notice
  Route: PUT /notices/{id}
  Method: AJAX submission via $.easyAjax
- Cancel Button: Discard changes and return to previous view

NOTICE DETAIL VIEW

Access Methods:
- Click "View" button from notice list
- Click notice title from dashboard widget
- Direct route: /notices/{id}
- Modal display: AJAX-loaded content

Information Display:
- Notice Heading: Prominent title display
- Creation Date: Formatted date and time
- Recipients Information: List of employees/clients who received the notice
- Notice Description: Full content with preserved formatting
- Attachment List: Files attached to the notice

Action Buttons (Permission-Based):
- Edit Notice Button: Modify notice content
  Route: /notices/{id}/edit
  Permission: edit_notice
- Delete Notice Button: Remove notice with confirmation
  Route: DELETE /notices/{id}
  Permission: delete_notice
  Confirmation: SweetAlert dialog

Read Status Tracking (Admin Feature):
- Read By Section: Shows which employees have viewed the notice
- User List: Names and read timestamps
- Read Status Indicators: Visual confirmation of notice delivery

File Management:
- File List Display: All attached files with details
- File Actions:
  * View File: Open file in new tab/window
  * Download File: Direct file download
    Route: GET /notice-files/{id}/download
  * Delete File: Remove attachment (permission-based)
    Route: DELETE /notice-files/{id}
    Permission: delete_notice_files
    Confirmation: SweetAlert dialog

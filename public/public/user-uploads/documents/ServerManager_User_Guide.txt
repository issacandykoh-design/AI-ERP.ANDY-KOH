SERVER MANAGER MODULE - COMPREHENSIVE USER GUIDE

OVERVIEW
The Server Manager module provides comprehensive server infrastructure management functionality for tracking hosting services, domain registrations, and service providers. This module enables organizations to maintain detailed records of their web hosting accounts, domain portfolios, and provider relationships throughout their lifecycle.

MAIN INTERFACE FEATURES

1. SERVER MANAGER DASHBOARD
   Route: /account/server-manager/
   Controller: ServerManagerController@index
   
   1.1 DASHBOARD STATISTICS
   - Statistics API: /account/server-manager/statistics
     * Functionality: Displays real-time statistics for hosting, domains, and providers
     * Implementation: AJAX-loaded statistics cards with counts and status breakdowns
   
   - Recent Activities API: /account/server-manager/activities
     * Functionality: Shows recent activities and changes across all server resources
     * Implementation: Dynamic activity feed with timestamps and action descriptions

2. HOSTING MANAGEMENT SECTION
   Route: /account/hosting
   Controller: HostingController
   
   2.1 HOSTING LISTING PAGE
   - Main Interface: DataTable-powered listing with advanced filtering
   - Export Functionality: /account/server-manager/hosting/export-all
   - Quick Actions: /account/server-manager/hosting/apply-quick-action
   - Status Changes: /account/server-manager/hosting/change-status
   
   2.2 FILTER CONTROLS
   - Duration Filter: Dropdown selection for time-based filtering
     * Options: All Time, Last 30 Days, Last 90 Days, Last Year
     * Functionality: Filters hosting records based on creation/update dates
     * Implementation: JavaScript date range filtering via DataTable parameters
   
   - Status Filter: Multi-select dropdown for hosting status
     * Available Options: Active, Suspended, Expired, Cancelled
     * Functionality: Filters hosting based on operational status
     * Implementation: Status-based filtering with badge display
   
   - Provider Filter: Dropdown selection to filter by hosting provider
     * Functionality: Shows hosting accounts from specific providers
     * Implementation: Provider data populated from database relationships
   
   - Search Field: Text input for comprehensive hosting search
     * Functionality: Searches across hosting names, IP addresses, and descriptions
     * Implementation: Real-time search with debounced input handling
   
   2.3 ACTION BUTTONS
   - Add New Hosting: Opens hosting creation modal/form
     * Route: /account/hosting/create
     * Permission Required: add_hosting
     * Functionality: Creates new hosting account records
   
   - Quick Actions Dropdown: Bulk operations for selected hostings
     * Change Status: Bulk status updates for multiple hostings
     * Delete Selected: Bulk deletion with confirmation
     * Export Selected: Export filtered hosting data
   
   2.4 HOSTING CREATION INTERFACE
   Route: /account/hosting/create
   AJAX Route: servermanager::hosting.ajax.create
   
   - Hosting Information Fields:
     * Hosting Name: Required text field for hosting account identification
     * Provider: Dropdown selection with "Add New Provider" option
     * Provider URL: Auto-populated from selected provider
     * Server Type: Dropdown selection (Shared, VPS, Dedicated, Cloud, etc.)
     * Server Location: Text field for data center location
     * IP Address: Text field for server IP address
     * cPanel URL: URL field for control panel access
     * Username: Text field for hosting account username
     * Password: Password field with visibility toggle
   
   - Billing Information Fields:
     * Purchase Date: Date picker for hosting purchase date
     * Renewal Date: Date picker for next renewal date
     * Billing Cycle: Dropdown (Monthly, Quarterly, Semi-Annual, Annual)
     * Annual Cost: Numeric field for hosting cost
   
   - Association Fields:
     * Associated Project: Dropdown selection from available projects
     * Client: Dropdown selection from client database
     * Status: Dropdown (Active, Suspended, Expired, Cancelled)
   
   2.5 HOSTING DETAIL VIEW
   Route: /account/hosting/{id}
   AJAX Template: servermanager::hosting.ajax.show
   
   - Status Banner: Visual status indicator with renewal warnings
     * Active: Green banner with renewal date if within 30 days
     * Suspended: Orange banner with suspension details
     * Expired: Red banner with expiry information
     * Cancelled: Gray banner with cancellation date
   
   - Information Sections:
     * Hosting Information: Complete hosting account details
     * Associated Domains: List of domains hosted on this account
     * Billing Information: Cost, billing cycle, and payment history
     * Statistics: Usage statistics and performance metrics
     * Activities: Recent changes and activity log
   
   - Action Modals:
     * Renew Hosting: Modal for extending hosting subscription
     * Suspend Hosting: Modal for temporary suspension
     * Download Backup: Backup download functionality
     * View Logs: Server log viewing interface
     * Add Domain: Associate new domains with hosting
   
   2.6 HOSTING EDIT INTERFACE
   Route: /account/hosting/{id}/edit
   AJAX Route: servermanager::hosting.ajax.edit
   
   - Pre-populated form with all hosting information

===========================================
PERMISSION SYSTEM
===========================================

HOSTING PERMISSIONS:
- add_hosting: Create new hosting accounts
- view_hosting: Access hosting records
- edit_hosting: Modify hosting information
- delete_hosting: Remove hosting accounts

DOMAIN PERMISSIONS:
- add_domain: Create new domain records
- view_domain: Access domain information
- edit_domain: Modify domain details
- delete_domain: Remove domain records

PROVIDER PERMISSIONS:
- add_provider: Create new provider records
- view_provider: Access provider information
- edit_provider: Modify provider details
- delete_provider: Remove provider records

PERMISSION LEVELS:
- all: Complete access to all records
- added: Access to user-created records
- owned: Access to assigned records
- both: Combined added and owned access
- none: No access to functionality

TECHNICAL FEATURES
===========================================

DNS LOOKUP SERVICE:
- Real-time DNS record retrieval using multiple DNS APIs
- Support for Google DNS, Cloudflare DNS, and OpenDNS
- Configurable DNS record types (A, AAAA, CNAME, MX, TXT, NS, SOA, PTR)
- DNS caching with configurable duration (default: 5 minutes)
- Error handling and fallback mechanisms
- DNS health monitoring and validation

DATA EXPORT FUNCTIONALITY:
- Excel export for hosting, domain, and provider data
- Filtered export based on current view settings
- Bulk export capabilities for selected records
- Export classes: HostingExport, DomainExport, ProviderExport

NOTIFICATION SYSTEM:
- Expiry notifications for hosting and domains
- Configurable reminder periods (30 days for hosting, 60 days for SSL)
- Email notifications for upcoming renewals
- System alerts for expired services

BACKGROUND JOBS:
- CheckExpiringHostingsJob: Automated hosting expiry checking
- CheckExpiringDomainsJob: Automated domain expiry monitoring
- Scheduled execution for proactive notifications

EVENT SYSTEM:
- HostingCreated, HostingUpdated events
- DomainCreated, DomainUpdated events
- Event listeners for automated actions
- Observer pattern for model lifecycle management

===========================================
CONFIGURATION OPTIONS
===========================================

DNS SERVICE CONFIGURATION:
- DNS_API_KEY: API key for DNS services (optional for public APIs)
- DNS_API_URL: Primary DNS API endpoint
- DNS_TIMEOUT: DNS lookup timeout (default: 10 seconds)
- DNS_CACHE_DURATION: Cache duration (default: 300 seconds)

MODULE SETTINGS:
- Hosting auto-renewal reminder days: 30
- SSL reminder days: 60
- Backup reminder days: 7
- Domain expiry reminder days: 30

FEATURE FLAGS:
- dns_lookup: Enable/disable DNS lookup functionality
- dns_health_check: Enable/disable DNS health monitoring
- whois_lookup: Enable/disable WHOIS functionality
- ssl_checker: Enable/disable SSL certificate checking

REPORTS MODULE - COMPREHENSIVE USER GUIDE

==================================================
MODULE OVERVIEW
==================================================

The Reports module provides comprehensive reporting and analytics capabilities across all business functions within the ERP system. This module enables users to generate, view, and analyze various types of reports including task reports, time log reports, financial reports, expense reports, leave reports, attendance reports, sales reports, and lead reports. Each report type offers advanced filtering options, data visualization through charts, and export capabilities.

==================================================
ACCESS AND PERMISSIONS
==================================================

PERMISSION REQUIREMENTS:
- view_task_report: Access to task-related reports
- view_timelogs: Access to time log reports  
- view_expense_report: Access to expense reports
- view_finance_report: Access to financial reports
- view_income_expense_report: Access to income vs expense reports
- view_leave_report: Access to leave reports
- view_attendance_report: Access to attendance reports
- view_lead_report: Access to lead reports
- view_sales_report: Access to sales reports

NAVIGATION ACCESS:
The Reports section is accessible through the main navigation menu, with individual report types displayed based on user permissions. Each report type appears as a separate menu item under the Reports section.

==================================================
MAIN INTERFACE FEATURES
==================================================

COMMON FILTER COMPONENTS:
All report interfaces include standardized filter sections with the following elements:

1. DATE RANGE FILTER
   - Input field for selecting date ranges
   - Placeholder text: "Select date range"
   - Uses daterangepicker component for easy date selection
   - Default range typically set to current month

2. DROPDOWN FILTERS
   - Employee selection with live search capability
   - Project selection with live search capability
   - Client selection with live search capability (where applicable)
   - Category selection for specific report types
   - Status filters for various report types

3. RESET FILTERS BUTTON
   - Clear all applied filters
   - Hidden by default, appears when filters are applied
   - Icon: times-circle
   - Text: "Clear Filters"

4. MORE FILTERS SECTION
   - Expandable section for additional filter options
   - Contains advanced filtering options specific to each report type

TASK REPORTS SECTION
==================================================

MAIN TASK REPORT
Route: /task-report
Controller: TaskReportController@index
Permission: view_task_report

INTERFACE FEATURES:
- Date range filter for task completion periods
- Status filter with options: All, Hide Completed Tasks, and custom task board statuses
- Project filter with live search functionality
- Advanced filters including client selection, assigned to, assigned by, task categories, and labels
- Data table displaying task information with sorting and pagination
- Chart visualization showing task distribution

FILTER OPTIONS:
- Duration: Date range picker for filtering tasks by date
- Status: Dropdown with task status options
- Project: Searchable dropdown of available projects
- Client: Searchable dropdown of clients (in more filters)
- Assigned To: Searchable dropdown of employees (in more filters)
- Assigned By: Searchable dropdown of employees (in more filters)
- Categories: Task category selection (in more filters)
- Labels: Task label selection (in more filters)

EMPLOYEE-WISE TASK REPORT
Route: /employee-wise-task-report
Controller: TaskReportController@employeeWiseTaskReport
Permission: view_task_report

INTERFACE FEATURES:
- Date range filter for task analysis period
- Employee filter for specific employee task reports
- Warning alert about missed deadline column
- Navigation tabs for switching between different task report views
- Data table with employee-specific task metrics

NAVIGATION TABS:
- Task Report: General task reporting (list icon)
- Employee-wise Task Report: Current active tab (people icon)
- Consolidated Task Report: Consolidated view (calendar icon)

CONSOLIDATED TASK REPORT
Route: /consolidated-task-report
Controller: TaskReportController@consolidatedTaskReport
Permission: view_task_report

INTERFACE FEATURES:
- Similar filtering options as main task report
- Consolidated view of task data across all employees
- Chart visualization for task analytics
- Export functionality for consolidated data

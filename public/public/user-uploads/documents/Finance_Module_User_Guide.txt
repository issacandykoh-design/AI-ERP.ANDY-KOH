FINANCE MODULE USER GUIDE

===========================================
OVERVIEW
===========================================

The Finance module is a comprehensive financial management system that handles all monetary transactions, billing, and financial reporting within the ERP system. It provides complete functionality for managing invoices, estimates, payments, expenses, credit notes, proposals, orders, recurring transactions, and financial reports.

===========================================
1. INVOICES MANAGEMENT
===========================================

1.1 INVOICE INTERFACE
The Invoice interface provides comprehensive invoice management capabilities with advanced filtering and bulk operations.

MAIN FEATURES:
- Duration-based filtering with date range picker
- Client-based filtering (for non-client users)
- Project-based filtering
- Invoice status filtering (pending, unpaid, paid, partial, canceled, pending-confirmation)
- Real-time search functionality
- Bulk operations with quick actions

ACTION BUTTONS:
- Add Invoice: Creates new invoice (/invoices/create)
- Add Recurring Invoice: Creates recurring invoice template (/recurring-invoices/create)
- Create Timelog Invoice: Generates invoice from timelogs (/invoices/create-timelog)

QUICK ACTIONS:
- Change Status: Bulk status modification
- Delete: Bulk invoice deletion
- Export: Data export functionality

1.2 INVOICE OPERATIONS
- Invoice Creation: Complete invoice generation with item management
- Invoice Editing: Modify existing invoice details
- Invoice Approval: Workflow-based approval system
- Invoice Sending: Email delivery to clients
- Payment Recording: Track payments against invoices
- Credit Application: Apply credit notes to invoices
- File Management: Upload and manage invoice attachments
- Status Management: Track invoice lifecycle (draft, sent, paid, overdue)

ROUTE MAPPINGS:
- Index: /invoices
- Create: /invoices/create
- Edit: /invoices/{id}/edit
- Show: /invoices/{id}
- Payment Details: /invoices-payment-details
- File Upload: /invoices/file-upload
- Send Invoice: /invoices/send-invoice
- Payment Reminder: /invoices/payment-reminder
- Download: /invoices/download/{id}
- Convert to Invoice: /invoices/convert-estimate/{id}

===========================================
14. WORKFLOW PROCESSES
===========================================

14.1 INVOICE WORKFLOW
1. Create Invoice → Add Items → Review → Send to Client
2. Client Receives → Makes Payment → Payment Recorded
3. Invoice Marked as Paid → Generate Receipt

14.2 EXPENSE WORKFLOW
1. Employee Submits Expense → Manager Reviews
2. Approved/Rejected → If Approved → Reimbursement Processed
3. Expense Recorded in Financial Reports

14.3 ESTIMATE WORKFLOW
1. Create Estimate → Send to Client → Client Reviews
2. Accepted → Convert to Invoice → Follow Invoice Workflow
3. Declined → Archive or Revise

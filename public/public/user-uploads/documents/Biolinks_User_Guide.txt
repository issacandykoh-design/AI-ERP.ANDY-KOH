BIOLINKS MODULE - COMPREHENSIVE USER GUIDE

OVERVIEW
The Biolinks module enables users to create personalized landing pages with multiple content blocks and customizable settings. Users can build professional bio pages with links, media, contact forms, and payment options.

MAIN NAVIGATION AND ACCESS
- Access Point: Navigate to Biolinks section from main menu
- Permission Required: Module access control via middleware
- Base URL Structure: /account/biolinks for management interface

BIOLINKS MANAGEMENT INTERFACE

1. BIOLINKS LISTING PAGE
Location: /account/biolinks
Features:
- Search Filter: Text input field to search existing biolinks by name or URL
- Reset Filters Button: Clears all applied search filters
- Add Biolink Page Button: Creates new biolink (requires create permission)
- DataTable Display: Shows all biolinks with sortable columns
- Status Toggle: Change biolink active/inactive status via AJAX
- Delete Function: Remove biolinks with confirmation dialog
- Edit Access: Click on biolink to access editing interface

2. CREATE NEW BIOLINK
Access: Click "Add Biolink Page" button
Modal Interface:
- Biolink Page URL Field: Enter custom URL slug (required)
- URL Preview: Shows full URL path with domain prefix
- Save Button: Creates biolink and redirects to edit interface
- Cancel Button: Closes modal without saving
Route: POST /account/biolinks (biolinks.store)

3. BIOLINK EDITING INTERFACE
Access: Click on existing biolink from listing
Layout: Split-screen with editing panel (left) and live preview (right)

Main Components:
- Page Title Display: Shows current biolink URL
- Edit URL Button: Modify biolink slug
- Live Preview: Real-time iframe showing biolink appearance
- Tab Navigation: Switch between Settings and Blocks

URL EDITING FUNCTIONALITY
- Edit Icon: Click pencil icon next to URL
- Modal Interface: Update biolink slug
- Validation: Ensures unique URL paths
Route: PUT /account/biolinks/{id}/edit-slug (biolinks.editSlug)

PUBLIC BIOLINK PAGE FEATURES

1. PAGE ACCESS AND SECURITY
URL Structure: /{biolink-slug}
Route: GET /{slug} (biolink.index)

Security Features:
- Password Protection: Intermediate password page if enabled
- Sensitive Content Warning: Optional content warning page
- Session Management: Remembers authentication status

Password Protection Flow:
1. User visits protected biolink
2. Password page displays if not authenticated
3. Password submission validates against stored hash
4. Success grants session access to biolink
Route: POST /{slug}/check-password (biolink.check-password)

Sensitive Content Flow:
1. Warning page displays if enabled
2. User acknowledges content warning
3. Session flag set for direct access
Route: GET /{slug}/check-sensitive (biolink.check-sensitive)

2. PAGE DISPLAY AND INTERACTION
Layout Structure:
- Responsive Design: Mobile-first responsive layout

Interactive Elements:

3. EMAIL COLLECTION FUNCTIONALITY
Modal Interface:
- AJAX Modal: Opens email collection form

Process Flow:

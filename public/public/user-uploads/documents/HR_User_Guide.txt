HR MODULE USER GUIDE
====================

This comprehensive guide covers all Human Resources (HR) functionalities within the ERP system, providing detailed explanations of features, navigation paths, and user interactions for optimal HR management.

1. EMPLOYEE MANAGEMENT
======================

1.1 EMPLOYEE LISTING AND OVERVIEW
----------------------------------
URL: /employees
Route: employees.index

The employee listing page provides comprehensive employee management capabilities with advanced filtering and search options.

Filter Options:
- Employee Selection: Filter by specific employees using searchable dropdown
- Designation Filter: Filter employees by job designation/position
- Department Filter: Filter by organizational departments
- Reporting Manager Filter: Filter by employees' reporting managers
- Employee Role Filter: Filter by system roles (admin, employee, client, etc.)
- Status Filter: Filter by active/inactive employee status
- Gender Filter: Filter by male/female/other gender categories
- Employment Type Filter: Filter by employment categories:
  * Probation: Employees in probationary period
  * Internship: Intern employees
  * Notice Period: Employees serving notice
  * New Hires: Recently joined employees
  * Long Standing: Long-term employees

Search Functionality:
- Global search field for employee names, emails, and employee IDs
- Real-time search with instant results
- Clear filters button to reset all applied filters

Action Buttons (Permission-based):
- Add New Employee: Create new employee records (requires add_employees permission)
- Invite Employee: Send invitation emails to new employees
- Import from Excel: Bulk import employee data from Excel files
- Export Options: Export employee data in various formats

Employee List Display:
- Employee photo/avatar with fallback initials
- Employee ID and full name with salutation
- Email address and contact information
- Designation and department details
- Joining date and employment status
- Role assignment and permissions level
- Last login timestamp
- Action buttons for individual employee management

1.2 EMPLOYEE CREATION AND REGISTRATION
--------------------------------------
URL: /employees/create
Route: employees.create
Modal URL: /employees/ajax/create

The employee creation form provides comprehensive data collection for new employee registration.

Account Details Section:
- Employee ID: Auto-generated or manual entry with validation
- Salutation: Title selection (Mr., Ms., Dr., etc.)
- Full Name: Required field with validation
- Email Address: Unique email with validation
- Date of Birth: Date picker with age validation
- Designation: Searchable dropdown with add new option (requires add_designation permission)
- Department: Searchable dropdown with add new option (requires add_department permission)
- Profile Picture: Image upload with cropping functionality (supports PNG, JPG, JPEG, SVG, BMP)

Contact Information:
- Country Selection: Searchable dropdown with flag icons
- Mobile Number: International format with country code selection
- Address: Multi-line text field for complete address
- About Me: Biographical information text area

Employment Details:
- Gender: Male/Female/Others selection
- Joining Date: Required date field with date picker
- Reporting Manager: Searchable employee dropdown
- Language Preference: System language selection with flag icons
- Role Assignment: System role selection with permissions

Additional Settings:
- Login Access: Enable/disable system login capability
- Email Notifications: Enable/disable email notification preferences
- Hourly Rate: Compensation rate with currency symbol
- Slack Username: Integration with Slack workspace
- Skills/Tags: Comma-separated skill tags with autocomplete

Employment Type Configuration:
- Employment Type: Full-time, Part-time, Contract, Internship, Trainee
- Probation End Date: For probationary employees
- Notice Period Dates: Start and end dates for notice period
- Contract End Date: For contract employees (conditional field)
- Internship End Date: For interns (conditional field)

Personal Information:
- Marital Status: Single, Married, Divorced, Widowed options
- Marriage Anniversary: Date field (conditional on marital status)
- Company Address: Business location assignment

Integration Features:
- Telegram Integration: User ID for Telegram notifications (if enabled)
- Custom Fields: Additional configurable fields based on company requirements

Form Actions:
- Save: Create employee and return to listing
- Save & Add More: Create employee and open new form
- Cancel: Discard changes and close form

1.3 EMPLOYEE PROFILE MANAGEMENT
-------------------------------
URL: /employees/{id}
Route: employees.show

The employee profile provides comprehensive employee information management with tabbed navigation.

Profile Overview:
- Employee photo with edit capability
- Full name with salutation and country flag
- Designation and department information
- Role assignment and permissions level
- Last login timestamp and activity status
- Employment status indicator (active/inactive)

Quick Statistics (for authorized users):
- Open Tasks Count: Number of pending tasks assigned
- Projects Count: Number of projects employee is involved in
- Hours Logged: Total time logged by employee
- Tickets Count: Number of support tickets assigned

Profile Information Display:
- Employee ID and full name
- Designation and department details
- Gender with appropriate icon
- Work anniversary calculation and display
- Date of birth (month and day only for privacy)
- Email address and mobile number (for authorized users)
- Slack username integration
- Hourly rate information (for authorized users)

Profile Tabs Navigation:
Each tab provides specific employee information based on user permissions:

1.3.1 Profile Tab
URL: /employees/{id}?tab=profile
- Complete employee information display
- Personal and professional details
- Contact information and preferences
- Employment history and status

1.3.2 Projects Tab
URL: /employees/{id}?tab=projects

- Project roles and responsibilities
- Project status and progress information
- Project timeline and milestones

1.3.3 Tasks Tab

- Task priorities and deadlines
- Task completion statistics
- Task performance metrics

1.3.4 Attendance Tab

Permission: view_attendance != 'none' and != 5
- Daily attendance records
- Clock in/out times and locations
- Attendance statistics and patterns
- Late arrivals and early departures
- Monthly attendance summaries

1.3.5 Leaves Tab
URL: /employees/{id}?tab=leaves
Permission: view_leave = 'all' or owned access
- Leave application history
- Leave balances and quotas
- Leave approval status
- Leave calendar view
- Leave statistics and trends

1.3.6 Leave Quota Tab
URL: /employees/{id}?tab=leaves-quota
- Annual leave entitlements
- Leave type allocations
- Used vs. available leave days
- Leave policy compliance
- Quota adjustments and history

1.3.7 Time Logs Tab
URL: /employees/{id}?tab=timelogs
Permission: view_employee_timelogs = 'all'
- Detailed time tracking records
- Project-wise time allocation
- Billable vs. non-billable hours
- Time log approval status
- Productivity analytics

1.3.8 Documents Tab
URL: /employees/{id}?tab=documents
Permission: view_documents != 'none'
- Employee document repository
- Contract documents and agreements
- Certificates and qualifications
- Identity and compliance documents
- Document version control

1.3.9 Emergency Contacts Tab
URL: /employees/{id}?tab=emergency-contacts
Permission: manage_emergency_contact = 'all' or own access
- Emergency contact information
- Relationship details and priorities
- Contact verification status
- Multiple contact management

1.3.10 Increment/Promotions Tab
URL: /employees/{id}?tab=increment-promotions
Permission: view_increment_promotion != 'none'
- Salary increment history
- Promotion records and dates
- Performance review outcomes
- Career progression tracking

1.3.11 Tickets Tab
URL: /employees/{id}?tab=tickets
Permission: view_tickets = 'all'
- Support tickets assigned to employee
- Ticket resolution statistics
- Customer service metrics
- Ticket priority and status tracking

1.3.12 Appreciation Tab
URL: /employees/{id}?tab=appreciation
Permission: view_appreciation (non-client users)
- Employee recognition records
- Awards and achievements
- Peer appreciation messages
- Recognition statistics and trends

1.3.13 Shifts Tab
URL: /employees/{id}?tab=shifts
Permission: view_shift_roster = 'all'
- Shift schedule assignments
- Shift pattern preferences
- Shift change requests
- Roster compliance tracking

1.3.14 Permissions Tab
URL: /employees/{id}?tab=permissions
Permission: manage_role_permission_setting = 'all'
- System permission assignments
- Role-based access control
- Permission modification history
- Security access levels

1.3.15 Activity Tab
URL: /employees/{id}?tab=activity
- Employee system activity log
- Login/logout timestamps
- Feature usage statistics
- Audit trail information

1.3.16 Immigration Tab
URL: /employees/{id}?tab=immigration
Permission: view_immigration = 'all' or owned access
- Visa and work permit information
- Immigration status tracking
- Document expiry alerts
- Compliance monitoring

3. LEAVE MANAGEMENT
===================

3.1 LEAVE OVERVIEW AND ADMINISTRATION
-------------------------------------
URL: /leaves
Route: leaves.index

The leave management system provides comprehensive leave tracking, approval workflows, and reporting capabilities.

Filter Options:
- Date Range Filter: Select specific date periods for leave data
- Employee Filter: Filter by specific employees
- Leave Type Filter: Filter by leave categories (Annual, Sick, Personal, etc.)
- Status Filter: Filter by approval status:
  * Approved: Confirmed leave applications
  * Pending: Awaiting approval leave requests
  * Rejected: Declined leave applications

Search and Navigation:
- Global search field for employee names and leave details
- Clear filters button to reset all applied filters
- Advanced search with multiple criteria

Action Buttons (Permission-based):
- Add New Leave: Create new leave applications (requires add_leave permission)
- Export to Excel: Download leave reports in Excel format
- Bulk Actions: Mass operations on selected leave records
  * Change Status: Bulk approval/rejection of leave applications
  * Delete Leaves: Bulk deletion of leave records (requires appropriate permissions)

Leave Display Features:
- Employee information with photo and designation
- Leave type and category classification
- Leave duration (full day, half day, hourly)
- Leave dates with calendar integration
- Approval status with color-coded indicators
- Approver information and approval timestamps
- Leave balance impact calculation

3.2 LEAVE APPLICATION PROCESS
-----------------------------
URL: /leaves/create
Route: leaves.create

Leave Application Form:
- Employee Selection: Choose employee for leave application
- Leave Type Selection: Choose from configured leave types
- Date Selection: Start and end date with calendar picker
- Duration Options: Full day, half day (morning/evening), hourly leave
- Reason Field: Detailed explanation for leave request
- Attachment Upload: Supporting documents (medical certificates, etc.)

Leave Balance Validation:
- Real-time balance checking against available quota
- Leave policy compliance verification
- Overlapping leave detection and prevention
- Holiday and weekend consideration

Approval Workflow:
- Automatic routing to designated approvers
- Multi-level approval process support
- Email notifications to approvers and applicants
- Approval history and audit trail

3.3 LEAVE QUOTA MANAGEMENT
--------------------------
URL: /employees/{id}?tab=leaves-quota
Route: employees.show with leaves-quota tab

Leave Quota Administration:
- Annual leave entitlement configuration
- Leave type allocation and limits
- Carry-forward policy implementation
- Pro-rata calculation for new joiners

Quota Tracking:
- Used vs. available leave days display
- Leave balance calculations and updates
- Quota expiry date monitoring
- Leave accrual rate configuration

Quota Adjustments:
- Manual quota modifications with justification
- Bonus leave allocation for special circumstances
- Leave encashment processing
- Quota transfer between leave types

5. EMPLOYEE SHIFT MANAGEMENT
============================

5.1 SHIFT SCHEDULING AND ROSTER MANAGEMENT
------------------------------------------
URL: /employee-shifts
Route: employee-shifts.index

The shift management system provides comprehensive scheduling capabilities for managing employee work patterns and roster assignments.

Shift Configuration Display:
- Shift Name: Descriptive identifier for shift patterns
- Shift Timing: Start and end times with timezone support
- Timing Type: Strict vs. Flexible hour enforcement
- Late Mark Duration: Grace period before marking late arrival
- Check-ins Per Day: Number of required clock-ins/outs
- Office Open Days: Working days configuration for each shift

Shift Management Actions:
- Edit Shift: Modify existing shift configurations
- Delete Shift: Remove shift patterns (with confirmation)
- Set Default Shift: Assign default shift for new employees
- Shift Assignment: Assign specific shifts to employees

Shift Types and Patterns:
- Fixed Shifts: Standard working hours with strict timing
- Flexible Shifts: Variable working hours within defined ranges
- Rotating Shifts: Alternating shift patterns for employees
- Split Shifts: Multiple work periods within a single day

Roster Planning:

Shift Compliance Monitoring:

# Brand assets

此目录用于存放品牌相关的图片素材（logo、字标等）。

目前已添加：
- `craveva-logo-white.svg`：白色 SVG 版 wordmark（占位用，方便在深色背景使用）。

如果你有官方矢量或透明 PNG：
- 将文件命名为 `craveva-logo-white.svg` 或 `craveva-logo-white.png` 覆盖即可；
- 如果包含中文标注版本，可另存为 `craveva-logo-cn-white.svg`。

使用示例：
```jsx
<img src="/img/brand/craveva-logo-white.svg" alt="Craveva" />
```

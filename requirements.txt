# ================================
# INSTALLATION NOTES
# ================================

# Main CRAVEVA ERP System
# 1. Install PHP with required extensions
# 2. Install Composer globally
# 3. Install Node.js and NPM
# 4. Run: composer install --no-dev --optimize-autoloader
# 5. Run: npm install --production
# 6. Run: npm run production
# 7. Configure .env file
# 8. Run: php artisan key:generate
# 9. Run: php artisan migrate
# 10. Set proper file permissions
# 11. Configure web server virtual host
# 12. Set up SSL certificate (production)
# 13. Configure cron jobs for scheduled tasks

# AI Enterprise Business Module
# 14. Install Python 3.8+ (recommended 3.12)
# 15. Navigate to AI_Enterprise_Business directory
# 16. Run: pip install -r requirements.txt
# 17. Configure .env file for AI module
# 18. Run: python main.py (for backend API)
# 19. Navigate to frontend directory
# 20. Run: npm install
# 21. Run: npm run build
# 22. Configure proxy settings for AI integration

# Craveva Landing Page Module
# 23. Navigate to Craveva_Landingpage directory
# 24. Run: npm install
# 25. Run: npm run build (for production)
# 26. Run: npm run dev (for development)
# 27. Configure base path in vite.config.js if needed
# 28. Integrate with main application routing

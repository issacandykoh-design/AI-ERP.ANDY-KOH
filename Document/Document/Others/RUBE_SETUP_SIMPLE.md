# Rube Setup - Super Simple Version

## Just 3 Steps!

### 1️⃣ Add Rube to Cursor
1. Press `Ctrl + ,` in Cursor
2. Search for "MCP"
3. Click "Add MCP Server"
4. Enter:
   - Name: `rube`
   - Type: `streamableHttp`
   - URL: `https://rube.app/?agent=cursor`
5. Click "Save"

### 2️⃣ Get API Key
1. Go to: https://rube.app/
2. Sign up/Login
3. Click "Install Rube" → Select "Cursor"
4. Copy the API key

### 3️⃣ Connect
1. Back in Cursor, find "rube" server
2. Paste API key in the "API Key" field
3. Click "Save"
4. Go to rube.app → Connect Google Drive
5. Done! ✅

**Test it:** Press `Ctrl + I` and type: "List my Google Drive files"

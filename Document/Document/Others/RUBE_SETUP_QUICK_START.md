# Rube Setup - Quick Start Guide

## 🚀 Setup in 5 Minutes

### Step 1: Open Cursor Settings
- Press `Ctrl + ,` (Windows) or `Cmd + ,` (Mac)

### Step 2: Search for MCP
- Type "MCP" in the settings search bar
- Or navigate to: **Settings → Features → MCP**

### Step 3: Add Rube Server
Click **"Add MCP Server"** and enter:

```
Name: rube
Type: streamableHttp  
URL: https://rube.app/?agent=cursor
```

### Step 4: Authenticate
1. Find "rube" in your MCP servers list
2. Click **"Authenticate"** or **"Login"**
3. Sign in to Composio (create account if needed)
4. Authorize Cursor

### Step 5: Connect Tools
1. After authentication, you'll see available tools
2. Click **"Connect"** for each tool you want:
   - ✅ Google Drive
   - ✅ Gmail
   - ✅ Slack
   - ✅ Notion
   - ✅ And 500+ more!

3. Complete OAuth flow for each tool in your browser

### Step 6: Test It!
Open Cursor chat (`Ctrl + I`) and try:
- "List my Google Drive files"
- "Send an email via Gmail"
- "Show me my Slack messages"
